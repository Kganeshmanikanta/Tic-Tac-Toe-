# 🎮 Tic Tac Toe Game – Java

## 📌 Overview

Tic Tac Toe is a console-based Java application that allows two players to play the classic Tic Tac Toe game on a 3×3 board.

The application uses a two-dimensional character array to represent the game board and Java control statements to manage player turns and game progression.

This project was developed to strengthen core Java programming skills and logical problem-solving abilities.

## ✨ Features

- **3×3 Game Board:** Uses a two-dimensional array to represent the game board.
- **Two-Player Gameplay:** Allows two players to take turns.
- **Interactive Console:** Accepts player input through the Scanner class.
- **Turn Management:** Switches between players after each valid move.
- **Winning Condition:** Checks rows, columns, and diagonals for a winning combination.
- **Draw Detection:** Identifies when the board is full without a winner.

## ▶️ How to Run

### Prerequisites
- Java JDK installed.
- Any Java IDE or command-line terminal.

### Using an IDE

1. Clone or download this repository.
2. Open the project in your preferred Java IDE.
3. Navigate to `src/pocs/TicTacToe.java`.
4. Run the `TicTacToe` class.
5. Follow the console instructions to play.

### Using Command Line

Clone the repository:

```bash
git clone https://github.com/Kganeshmanikanta/Tic-Tac-Toe-.git
```

Navigate to the project directory and compile:

```bash
javac -d out src/pocs/TicTacToe.java
```

Run the application:

```bash
java -cp out pocs.TicTacToe
```
